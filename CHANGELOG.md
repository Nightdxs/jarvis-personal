# Historial de cambios

## 3.0.0 — 2026-10-13

- Motor de conversación mediante Codex CLI autenticado con ChatGPT.
- Bloqueo del modo API de pago y Realtime en los lanzadores.
- Verificación de conexión con ChatGPT y eliminación del requisito de API key en el panel normal.
- Selector de voces, ajustes de tono/velocidad y prueba de lectura.
- Alternativa Windows + H para el error network del dictado web de Brave.
- Documentación de instalación, uso, arquitectura, integraciones, seguridad y validación.
- Capturas de una instalación limpia y 19 pruebas automatizadas.

## 2.0.0 — etapa anterior

- Voz Realtime, memoria selectiva, clima y copias de archivos para revisión.
- Herramientas con aprobación y vistas previas de proyectos estáticos.

## 1.0.0 — etapa inicial

- Panel local en español, notas Markdown y creación de webs con el motor API anterior.

Las etapas anteriores describen la evolución del proyecto; no indican que las funciones API de pago estén habilitadas en la versión actual.
