# Usar el plan de ChatGPT

El modo actual utiliza Codex con inicio de sesión de ChatGPT y los límites de ese plan. No necesita créditos de la API de OpenAI y no cambia automáticamente al modo de pago.

Consulta [Instalación](docs/INSTALACION.md), [Voz y dictado](docs/VOZ.md) y [Validación](docs/VALIDACION.md). No se promete uso ilimitado ni funcionamiento sin Internet.
